# coffee-shop-sales-analysis-dashboard

## Project Overview
An Excel-based sales analysis dashboard created to analyze 149K+ coffee shop transactions and identify meaningful business insights.

## Problem Statement
Raw transaction data can make it difficult to understand sales performance, product trends, store performance, and customer purchasing patterns. This project transforms transaction-level data into an interactive dashboard for easier analysis and decision-making.

## Key Analysis
- Overall revenue and sales performance
- Product and category performance
- Store location analysis
- Monthly sales trends
- Weekday and hourly sales patterns
- Top-performing products
- Key Performance Indicators (KPIs)

## Tools Used
- Microsoft Excel
- PivotTables
- Calculated Columns
- Excel Formulas
- Charts
- Slicers
- Data Visualization
- Dashboard Creation

## Key KPIs
- Total Revenue: ₹698,812
- Total Transactions: 149,116
- Total Quantity Sold: 214,470
- Average Transaction Value: ₹4.69

## Dashboard
The dashboard provides an interactive view of sales performance using KPIs, charts, PivotTables, and slicers.

## Skills Demonstrated
Excel | Data Analysis | Data Cleaning | PivotTables | Data Visualization | Dashboard Design | Business Analytics
